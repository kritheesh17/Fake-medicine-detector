Project Title

Fake Medicine Detector

Introduction

The Fake Medicine Detector is a software application designed to identify counterfeit medicines using barcode/QR code verification and database validation. The system helps users verify the authenticity of medicines before purchase or consumption.

Objectives

- Detect fake medicines.
- Verify medicine authenticity.
- Improve patient safety.
- Reduce counterfeit drug circulation.

Features

- Medicine barcode/QR code scanning.
- Medicine information retrieval.
- Authenticity verification.
- User-friendly interface.
- Database management.

Technologies Used

Frontend

- HTML
- CSS
- Bootstrap
- React

Backend

- Java
- Spring Boot

Database

- MySQL

Additional Technologies

- QR Code Scanner
- Email Notifications
- REST APIs

System Modules

1. User Registration

Users create an account and log in to the system.

2. Medicine Verification

Users scan or enter the medicine code.

3. Database Validation

The system checks the code against the database.

4. Result Display

Displays whether the medicine is genuine or fake.

5. Admin Management

Admin manages medicine records and manufacturer details.

Algorithm

1. Start
2. User scans QR/Barcode.
3. Receive medicine code.
4. Search code in database.
5. If code exists:
   - Display "Genuine Medicine".
6. Else:
   - Display "Fake Medicine".
7. End

Future Enhancements

- Blockchain integration.

Conclusion

The Fake Medicine Detector helps consumers identify counterfeit medicines quickly and accurately. It improves healthcare safety and ensures that only genuine medicines reach patients.
